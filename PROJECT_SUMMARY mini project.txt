Smart Resume Matcher - Project Summary🎯 Project OverviewA sophisticated full-stack application that uses semantic search and machine learning to intelligently match resumes with job descriptions. The system combines deep learning embeddings with customizable weights to provide recruiters with accurate, explainable matching scores.🏆 Key Achievements✅ Semantic Matching EngineUses `sentence-transformers` (all-MiniLM-L6-v2) for 384-dimensional embeddingsCalculates cosine similarity between resume and job descriptionsCaptures semantic meaning beyond keyword matchingSupports batch processing for multiple candidates✅ Intelligent Resume ParsingGoogle Gemini 1.5 Flash API integrationStructured JSON output with guaranteed schemaExtracts: name, skills, experience, education, certifications, languages, location, salaryFallback handling for parsing errors✅ Interactive Weight System7 customizable attributes with real-time updatesAutomatic weight normalizationVisual sliders for easy adjustmentInstant score recalculation✅ Professional UI/UXDark mode interface with gradient accentsRadar chart visualization of match scoresMulti-step form with progress indicatorResponsive design for all devicesDrag-and-drop file upload✅ Production-Ready BackendFastAPI with async/await supportCORS enabled for frontend integrationComprehensive error handlingHealth check and model info endpointsBatch matching capability📊 Architecture```┌─────────────────────────────────────────────────────────────┐│                    Frontend
